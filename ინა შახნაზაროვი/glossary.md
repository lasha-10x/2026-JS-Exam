# Tech Glossary

1. **Authentication** — The process of verifying a user's identity (e.g., email + password). / ავთენტიფიკაცია — მომხმარებლის ვინაობის დადასტურება.

2. **Session** — A period during which a user is logged in, stored in `crm_session`. / სესია — დრო, როცა მომხმარებელი შესულია სისტემაში.

3. **Validation** — Checking user input against rules before processing. / ვალიდაცია — მომხმარებლის მიერ შეყვანილი მონაცემების შემოწმება.

4. **fetch** — Browser API for making HTTP requests. / fetch — ბრაუზერის API HTTP მოთხოვნებისთვის.

5. **Endpoint** — A specific URL on an API (e.g., `/users/add`). / ენდპოინტი — კონკრეტული URL API-ზე.

6. **Request method** — HTTP verb: GET, POST, DELETE, PUT. / მოთხოვნის მეთოდი — HTTP ზმნა, მაგალითად GET, POST, DELETE ან PUT.

7. **JSON** — Data format used to exchange data between client and server. / JSON — მონაცემთა ფორმატი კლიენტსა და სერვერს შორის.

8. **State** — The current data of the app (e.g., clients array). / სტეიტი — აპლიკაციის მიმდინარე მონაცემები.

9. **Event listener** — A function that runs when an event occurs (click, submit). / ივენთ ლისენერი — ფუნქცია, რომელიც ივენთისას ირთვება.

10. **Deployment** — Publishing the app to a live server (Vercel/Netlify). / დეპლოი — აპის ცოცხალ სერვერზე განთავსება.
