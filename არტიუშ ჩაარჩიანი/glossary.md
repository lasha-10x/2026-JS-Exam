# Technical Glossary

## 1. Authentication

**English:** Authentication is the process of verifying that a user is who they claim to be, typically through credentials like email and password.

**Georgian:** ავთენტიკაცია არის პროცესი, რომლით შემოდგომა იმისათვით რომ მომხმარებელი იცის თავი, მაგალითად ელფოსტისა და პაროლის მიხედვით.

## 2. Session

**English:** A session represents the active login state of a user, stored to maintain authentication across multiple page visits.

**Georgian:** სესია არის მომხმარებლის აქტიური სირულის მდგომარეობა, რომელიც შენახული ირება ბრაუზერის სესიების შემდეგაც და აძლევს სირულის შენახვის ავტომატურაული შეყვანას სხვა გვერდებზე.

## 3. localStorage

**English:** localStorage is a browser API that stores key-value pairs persistently on the client side, surviving browser restarts.

**Georgian:** localStorage არის ბრაუზერის API, რომელიც ქსელის კლიენტური გვერდიდან ქმედებს ქვები-ინერციებს მინიშვნელობების შენახვისთვის, და იგი შედგება ბრაუზერის გადატანის შემდეგაც.

## 4. Fetch API

**English:** The Fetch API provides a simple, modern interface for making HTTP requests from the browser to servers.

**Georgian:** Fetch API აწოდებს ბრაუზერისთვის სამუდმეო და მართავს ჰარსების მოთხოვნების გაკვეთის სირულის გასაღებისა და მიიღებისთვის პროცესს.

## 5. DOM

**English:** The Document Object Model (DOM) represents a web page as a tree of objects that JavaScript can manipulate.

**Georgian:** დოკუმენტონტრიული ობიექტის მოდელი (DOM) არის ვებ-გვერდის წინადადება ობიექტების ორწინადმენების სახით, როგორიც JavaScript-ი შეძლებს მანერებონის.

## 6. Event Listener

**English:** An event listener is a function that runs in response to specific user actions like clicks, inputs, or form submissions.

**Georgian:** მოვლენის მიმდინარეობის მსმენელი არის ფუნქცია, რომელით შესაძლებელია მომხმარებლის მოქმედებებზე (კლიკები, შეყვანა, ფორმის გაგზავნა) პასუხის გაცემა.

## 7. Validation

**English:** Validation checks that user input meets the required rules before data is processed or stored.

**Georgian:** ვალიდაცია ამოწმებს რომ მომხმარებლის შეყვნა ერთობლივი წრფივთვის დანერნებული პირობებს შედგებს მონაცემების დამუშავებისა და შენახვისგან მედიდინდგ.

## 8. JSON

**English:** JSON (JavaScript Object Notation) is a lightweight data format used for exchanging information between systems.

**Georgian:** JSON (JavaScript ობიექტის ნიშანი) არის საავტორიული დამათავსებელი ფორმატი, რომელით სისტემებობს შორს ინფორმაციის გარდაქმნისთვის გამოიყენება.

## 9. Module

**English:** A module is a self-contained piece of JavaScript code that can be imported and reused in other files.

**Georgian:** მოდული არის საცავიანე კოდის ნაჩვენება JavaScript-ის, რომელით შეძლება იმპორტირება და იყენება სხვა ფაილებზე.

## 10. API Endpoint

**English:** An API endpoint is a specific URL where an application can send requests and receive responses from a server.

**Georgian:** API-ის ენდპოინტი არის კონკრეტული მისამართი, სადაც აპლიკაცია შეძლება ჰარსების მოთხოვნების გაგზავნა და სერვერიდან პასუხების მიღება.
