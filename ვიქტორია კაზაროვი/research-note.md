# Research Note: Browser localStorage

[MDN Web Docs — Window: localStorage property](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage)

## ქართული რეზიუმე

MDN-ის მიხედვით, `localStorage` ბრაუზერში კონკრეტული origin-ისთვის მონაცემების შენახვის საშუალებას გვაძლევს და ეს მონაცემები ბრაუზერის სესიებს შორისაც რჩება.  
`localStorage` გასაღებებსა და მნიშვნელობებს ტექსტის სახით ინახავს, ამიტომ პროექტში ობიექტები და მასივები შენახვამდე `JSON.stringify()`-ით გარდაიქმნება.  
მონაცემის წასაკითხად გამოიყენება `getItem()`, ჩასაწერად `setItem()`, ხოლო კონკრეტული ჩანაწერის წასაშლელად `removeItem()`.  
ეს ცოდნა 10X CRM-ში მომხმარებლების, მიმდინარე სესიის, კლიენტებისა და არჩეული თემის შესანახად გამოვიყენე.  
წყარო ასევე განმარტავს, რომ `file:` მისამართიდან გახსნილი გვერდებისთვის storage-ის ქცევა ბრაუზერებს შორის შეიძლება განსხვავდებოდეს, ამიტომ პროექტის ლოკალური სერვერით გაშვება უფრო საიმედოა.  
`localStorage` სასარგებლოა სასწავლო მდგომარეობისა და პარამეტრების შესანახად, თუმცა რეალურ პროდუქტში ღია პაროლების შესანახად უსაფრთხო ადგილი არ არის.
