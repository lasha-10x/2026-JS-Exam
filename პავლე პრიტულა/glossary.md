# Project Glossary

| Term | English explanation | ქართული ახსნა |
|---|---|---|
| Authentication | Authentication verifies that a user can access an application. | ამოწმებს, შეუძლია თუ არა მომხმარებელს შესვლა. |
| Session | A session stores information about the currently logged-in user. | სესია ინახავს ინფორმაციას იმ მომხმარებელზე, რომელიც ახლა შესულია. |
| Validation | Validation checks whether form data follows required rules. | ვალიდაცია ამოწმებს, აკმაყოფილებს თუ არა ფორმის მონაცემები საჭირო წესებს. |
| localStorage | localStorage keeps key-value data in the browser after a page reload. | localStorage ბრაუზერში ინახავს მონაცემებს გვერდის გადატვირთვის შემდეგაც. |
| Fetch | Fetch is a browser API for making HTTP requests. | Fetch არის ბრაუზერის API, რომლითაც ვაგზავნით HTTP მოთხოვნებს. |
| Endpoint | An endpoint is a URL that provides a specific API operation. | endpoint არის URL, რომელიც API-ის კონკრეტულ მოქმედებას ასრულებს. |
| GET request | A GET request asks a server to return data. | მონაცემების GET მეთოდით წამოღება სერვერიდან. |
| POST request | A POST request sends new data to a server. | POST მოთხოვნა სერვერზე ახალ მონაცემს აგზავნის. |
| State | State is the current data that controls what the UI displays. | state არის მიმდინარე მონაცემები, რომლებიც განსაზღვრავს რას აჩვენებს ინტერფეისი. |
| Event listener | An event listener runs a function after a user or browser action. | event listener მომხმარებლის მოქმედებაზე დამოკიდებული ფუნქციის გაშვება |
