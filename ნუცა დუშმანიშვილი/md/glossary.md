technical glossary. არცისე ჩემი სიტყვებია, მარა გამეორება კი წამადგა...

1. Authentication
Authentication checks whether a user has provided valid login information.
ავტორიზაცია ამოწმებს, სწორია თუ არა მომხმარებლის მეილი და პაროლი.

2. Session
A session stores information about the user who is currently logged in.
სესია ინახავს ამჟამად შესული მომხმარებლის ინფორმაციას.

3. Validation
Validation checks whether form data follows the required rules.
ვალიდაცია ამოწმებს, სწორად არის თუ არა ფორმის ველები შევსებული.

4. Fetch
Fetch is a browser function used to send an HTTP request and receive data.
fetch ფუნქციით აპლიკაცია API-ს უგზავნის მოთხოვნას და იღებს მონაცემებს.

5. Endpoint
An endpoint is a specific API address used for an operation.
endpoint არის API-ს კონკრეტული მისამართი, მაგალითად `/users`.

6. Request Method
A request method describes the operation, such as GET, POST, or DELETE.
request method განსაზღვრავს მოქმედებას: GET იღებს, POST ამატებს, DELETE კი შლის მონაცემს.

7. JSON
JSON is a text format used to exchange structured data.
JSON არის ტექსტური ფორმატი, რომლითაც ობიექტები და მასივები გადაიცემა.

8. State
State is the current data used by the application interface.
state არის აპლიკაციის მიმდინარე მონაცემები, მაგალითად clients მასივი.

9. Event Listener
An event listener runs a function when an event happens.
event listener ელოდება მოქმედებას, მაგალითად click-ს ან submit-ს, და შემდეგ ფუნქციას უშვებს.

10. Deployment
Deployment makes a project available on the internet.
deployment პროექტს ინტერნეტში აქვეყნებს და აძლევს საჯარო ბმულს.
