# Glossary

## 1. localStorage

**Definition:** localStorage is a browser feature that stores data as key-value pairs and keeps it available after the page is refreshed or closed.

localStorage არის ლოკალური, ბრაუზერის მონაცემების შესანახი სივრცე სადაც ინფორმაცია key-value ფორმატით ინახება. ინფორმაცია ინახება გვერდის შეცვლის ან ბრაუზერის სესიის დასრულების შემდეგაც.
---

## 2. HTTP Request

**Definition:** An HTTP request is a message sent by an application to a server to retrieve, create, update, or delete data.

HTTP request არის მოთხოვნა, რომელიც იგზავნება ბრაუზერიდან სერვერზე. მოთხოვნა შეიძლება იყოს სერვერიდან არსებული მონაცემების მისაღებად, შესაცვლელად ან ახალი ინფორმაციის დასამატებლად. 
---

## 3. CRUD

**Definition:** CRUD stands for Create, Read, Update, and Delete, which are the four basic operations used to manage data.

CRUD არის აკრონიმი, რომელიც მოიცავს მონაცემებზე შესრულებულ ძირითად მოქმედებებს: შექმნა, წაკითხვა, განახლება და წაშლა. 

---

## 4. Route Guard

**Definition:** A route guard is a function that controls whether a user is allowed to access a particular page.

Route Guard ამოწმებს აქვს თუ არა წვდომა მომხმარებელს კონკრეტულ გვერდზე. მაგალითად, მომხმარებელს რომელიც არ არის ავტორიზებული ან არ აქვს შესაბამისი სტატუსი, შესაძლებელია არ ჰქონდეს წვდომა გარკვეულ გვერდებზე.
---

## 5. API

**Definition:** An API allows one application to request or exchange data with another service.

API არის პროტოკოლი რომელიც საშუალებას აძლევს პროგრამას დაუკავშირდეს სხვა სერვისს და მათ შორის მოხდეს მონაცემთა გაცვლა.
---

## 6. Fetch API

**Definition:** The Fetch API is a JavaScript interface used to send HTTP requests and receive responses.

fetch API არის ჯავასკრიპტის პროტოკოლი რომელიც გამოიყენება სხვა სერვისთან კომუნიკაციისათვის. ამ პროტოკოლის მეშვეობით ჯავასკრიპტი გზავნის მოთხოვნას და გზავნის/იღებს ინფორმაციას.
---

## 7. Asynchronous Code

**Definition:** Asynchronous code allows JavaScript to wait for operations such as API requests without blocking the rest of the application.

ასინქრონული კოდი საშუალებას აძლევს JS-ს რომ დაიწყოს ხანგრძილივი ოპერაციების შესრულება ისე რომ არ დაელოდოს მის დასრულებას და პროგრამას მუშაობა გაგრძელდეს ჩვეულებრივ. ანუ ასინქრონული ოპერაცია მუშაობს 'ბექგრაუნდში'.
---

## 8. DOM

**Definition:** The DOM is a JavaScript representation of an HTML document that allows page elements to be created, changed, or removed.

DOM არის html დოკუმენტის იერარქიული მოდელი, რომლის საშუალებითაც შესაძლებელია js-თი, დინამიურად შევქმნათ და ვცვალოთ ელემენტების სტრუქტურა, ატრიბუტები და სტილები.

## 9. Event Delegation

**Definition:** Event delegation uses one event listener on a parent element to handle events from multiple child elements.

Event Delegation-არის მიდგომა, რომლის დროსაც 'შვილ' ელემენტებზე რამდენიმე ტრიგერის (event listener)-ის დაყენების ნაცვლად, event listener-ს ვაყენებთ ერთ საერთო 'მშობელ' ელემენტზე. 

---

## 10. JSON

**Definition:** JSON is a text-based format used to store and exchange structured data.

JSON არის ტექსტის ფორმატი, რომელიც გამოიყენება ინფორმაციის შესანახად და გასაგზავნად/მისაღებად. JS-ში JSON.stringify() da json.parse() მეთოდები რომელიც JSON ფორმატის ტექსტს მარტივად გარდაქმნის JS ობიექტად და პირიქით.

---
