## 📝 5-6 წინადადებიანი ქართული რეზიუმე (Summary)

DummyJSON წარმოადგენს უფასო REST API სერვისს, რომელიც სპეციალურად შექმნილია ფრონტენდ დეველოპერებისთვის პროტოტიპირებისა და ტესტირებისთვის. პროექტში გამოყენებულია `/users` რესურსი, საიდანაც საწყის ეტაპზე `GET` მოთხოვნით წამოგვაქვს 30 ტესტური კლიენტის მონაცემები (`?limit=30`). სერვერზე ძებნის ფუნქციონალი რეალიზებულია `/users/search?q=query` ენდპოინტის მეშვეობით, სადაც საძიებო სიტყვა იგზავნება URL-ის პარამეტრად. API ასევე უზრუნველყოფს `POST`, `PUT` და `DELETE` მოთხოვნების სიმულაციას, თუმცა რეალურად სერვერზე ბაზას არ ცვლის და მხოლოდ წარმატებული პასუხის იმიტაციას ახდენს. ამ შეზღუდვის დასაძლევად, სერვერიდან წამოღებული მონაცემები ინტეგრირებულია ბრაუზერის `localStorage`-თან, სადაც ხდება კლიენტების საბოლოო შენახვა და განახლება. აღნიშნული დოკუმენტაციის საფუძველზე აიგო პროექტის მონაცემთა სტრუქტურა (`normaliseClient`), რამაც შესაძლებელი გახადა სრულფასოვანი CRM სისტემის შექმნა რეალური ბექენდის გარეშე.
