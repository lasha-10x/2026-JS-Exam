# 🚀 10X CRM - Client Relationship Management System

## 📌 About
10X CRM is a modern, responsive frontend web application designed for managing client relationships and tracking sales pipelines. Built purely using semantic HTML5, Vanilla CSS3, and modern JavaScript (ES6+), it delivers a fast and dynamic user experience without relying on heavy external frameworks. The application features full client CRUD management, dual List and Kanban view modes, real-time activity timers, and local data persistence.

---

## ✨ Features

- **Authentication & Security:** Sign up, log in, session persistence ("Remember Me"), and route protection guards.
- **Interactive Dashboard:** Live clock, total clients overview, active deals count, and revenue statistics.
- **Client CRUD Operations:** Add, edit, view details, and delete client profiles dynamically.
- **Dual View Modes:**
  - **List View:** Table format with pagination and "Load More" controls.
  - **Kanban Board:** Interactive Drag-and-Drop column status updates (*Lead*, *Contacted*, *Won*, *Lost*).
- **Search, Filtering & Sorting:** Debounced local and server search, filter chips by status, and sorting by name, deal value, or creation date.
- **Interactive Client Tools:** Timestamped notes timeline, live call duration timer, and Web Audio API synthesized reminder chimes.
- **CSV Data Export:** One-click export of current filtered/sorted client lists to CSV.
- **Theme & Profile Management:** Dark/Light mode toggle, user profile settings, and workspace data reset.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, Vanilla CSS3 (Flexbox & CSS Grid), JavaScript (ES6+)
- **APIs & Async Operations:** Fetch API, [DummyJSON API](https://dummyjson.com/), Web Audio API, Drag & Drop API
- **Storage:** Browser `localStorage` and `sessionStorage`
