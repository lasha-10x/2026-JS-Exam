# Glossary

| Term | English sentence | Georgian explanation |
| --- | --- | --- |
| Authentication | Authentication checks who the user is before allowing access. | მომხმარებლის იდენტობის შემოწმება სისტემაში შესვლამდე. |
| Session | A session stores the current logged-in user. | მიმდინარე ავტორიზებული მომხმარებლის შენახული მდგომარეობა. |
| Validation | Validation checks whether form input follows the rules. | ფორმის ველების წესებთან შესაბამისობის შემოწმება. |
| Fetch | Fetch sends a network request from the browser. | ბრაუზერიდან API მოთხოვნის გაგზავნა. |
| Endpoint | An endpoint is a specific API URL used by the app. | API-ის კონკრეტული მისამართი, რომელსაც აპლიკაცია იყენებს. |
| Request method | A request method describes the action, such as GET, POST, or DELETE. | მოთხოვნის მოქმედების ტიპი, მაგალითად GET, POST ან DELETE. |
| JSON | JSON is a text format for structured data. | სტრუქტურირებული მონაცემების ტექსტური ფორმატი. |
| State | State is the current data used to render the interface. | მიმდინარე მონაცემები, რომლითაც UI იხატება. |
| Event listener | An event listener runs code when the user interacts with the page. | კოდი, რომელიც მომხმარებლის მოქმედებაზე რეაგირებს. |
| Deployment | Deployment publishes the app so other people can open it online. | აპლიკაციის ინტერნეტში გამოქვეყნება. |
