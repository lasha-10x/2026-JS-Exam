# Technical English Glossary

1. **Authentication**: The process of verifying the identity of a user entering the system. (მომხმარებლის იდენტურობის დადასტურება სისტემაში შესვლისას).
2. **Session**: A temporary state stored to keep the user logged in across multiple pages. (დროებითი სესია მომხმარებლის ავტორიზაციის შესანარჩუნებლად).
3. **Validation**: Rules checking if user input data complies with specified conditions. (მონაცემთა ვალიდაცია წესებთან შესაბამისობაზე).
4. **Fetch**: A modern JavaScript browser API used to request data asynchronously from servers. (ასინქრონული მოთხოვნის გაგზავნა სერვერთან).
5. **Endpoint**: A specific URL where an API receives requests to perform operations. (API-ს კონკრეტული მისამართი).
6. **Request Method**: HTTP verbs (GET, POST, DELETE) dictating the desired action on resources. (სერვერთან მოქმედების ტიპი).
7. **JSON**: JavaScript Object Notation format used for structuring and exchanging data. (მონაცემთა გაცვლის ფორმატი).
8. **State**: Data stored in memory representing the current status of the application interface. (აპლიკაციის მიმდინარე მონაცემთა მდგომარეობა).
9. **Event Listener**: A function waiting for specific user interactions like clicks or input submits. (მოვლენის მიმღები/მსმენელი).
10. **Deployment**: Publishing web application files to online servers for public access. (პროექტის სერვერზე განთავსება და გაშვება).
