# 10X CRM Technical Glossary

## 1. Authentication

**English:** Authentication is the process of checking that a user is who they claim to be before granting access.

**ქართული:** ავთენტიფიკაცია არის მომხმარებლის ვინაობის შემოწმება, სანამ სისტემა დაცულ გვერდებზე წვდომას მისცემს.

## 2. Session

**English:** A session stores the information needed to recognize the currently logged-in user.

**ქართული:** სესია ინახავს მონაცემებს, რომლითაც აპლიკაცია ამოიცნობს ამჟამად შესულ მომხმარებელს.

## 3. Validation

**English:** Validation checks whether entered data follows the required rules before it is processed or saved.

**ქართული:** ვალიდაცია ამოწმებს, აკმაყოფილებს თუ არა შეყვანილი მონაცემი წესებს დამუშავებამდე ან შენახვამდე.

## 4. Fetch

**English:** `fetch()` is a browser function that sends an HTTP request and returns a Promise for the response.

**ქართული:** `fetch()` არის ბრაუზერის ფუნქცია, რომელიც აგზავნის HTTP მოთხოვნას და პასუხისთვის Promise-ს აბრუნებს.

## 5. Endpoint

**English:** An endpoint is a specific API URL used to request or change a resource.

**ქართული:** endpoint არის API-ის კონკრეტული მისამართი, საიდანაც რესურსს ვითხოვთ ან ვცვლით.

## 6. Request Method

**English:** A request method such as GET, POST, or DELETE describes the action an HTTP request should perform.

**ქართული:** მოთხოვნის მეთოდი, მაგალითად GET, POST ან DELETE, განსაზღვრავს HTTP მოთხოვნის მოქმედებას.

## 7. JSON

**English:** JSON is a text format used to represent structured data with objects, arrays, keys, and values.

**ქართული:** JSON არის ტექსტური ფორმატი, რომელიც ობიექტებით, მასივებით, გასაღებებითა და მნიშვნელობებით სტრუქტურირებულ მონაცემებს აღწერს.

## 8. State

**English:** State is the current data that determines what an application displays and how it behaves.

**ქართული:** state არის მიმდინარე მონაცემების მდგომარეობა, რომელიც განსაზღვრავს რას აჩვენებს და როგორ მუშაობს აპლიკაცია.

## 9. Event Listener

**English:** An event listener runs a function when a browser event such as click, input, change, or submit occurs.

**ქართული:** event listener უშვებს ფუნქციას, როდესაც ხდება ბრაუზერის მოვლენა, მაგალითად click, input, change ან submit.

## 10. Deployment

**English:** Deployment is the process of publishing an application so other people can access it online.

**ქართული:** deployment არის აპლიკაციის ინტერნეტში გამოქვეყნების პროცესი, რათა მასზე სხვა მომხმარებლებსაც ჰქონდეთ წვდომა.

## 11. LocalStorage

**English:** LocalStorage is browser storage that keeps string data after the page is refreshed or the browser is reopened.

**ქართული:** LocalStorage არის ბრაუზერის საცავი, რომელიც ტექსტურ მონაცემებს გვერდის განახლებისა და ბრაუზერის ხელახლა გახსნის შემდეგაც ინარჩუნებს.

## 12. DOM

**English:** The Document Object Model represents an HTML page as objects that JavaScript can read and update.

**ქართული:** Document Object Model HTML გვერდს ობიექტების სახით წარმოადგენს, რომელთა წაკითხვა და შეცვლა JavaScript-ს შეუძლია.

## 13. Promise

**English:** A Promise represents the future result of an asynchronous operation, such as an API request.

**ქართული:** Promise წარმოადგენს ასინქრონული მოქმედების მომავალ შედეგს, მაგალითად API მოთხოვნის პასუხს.

## 14. Async/Await

**English:** `async` and `await` provide a readable way to run asynchronous operations and wait for their results.

**ქართული:** `async` და `await` ასინქრონული მოქმედებების გაშვებისა და მათი შედეგების დალოდების გასაგები საშუალებაა.

## 15. Error Handling

**English:** Error handling uses logic such as `try...catch` to respond safely when an operation fails.

**ქართული:** შეცდომების დამუშავება იყენებს `try...catch`-ის მსგავს ლოგიკას, რათა წარუმატებელი მოქმედება უსაფრთხოდ დამუშავდეს.
